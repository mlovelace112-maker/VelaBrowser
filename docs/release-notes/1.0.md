Vela 1.0 is the first stable release: a fast, private, native Mac browser built on Safari's engine, with Claude built in.

## Browsing
- Tabs along the top that group similar sites into color-coded groups, plus pinned and private tabs
- Scrolling tab bar with hover previews, an all-tabs list, vertical tabs (⌃⌘V) and split view (⌥-click a tab)
- Containers (Personal, Work, Shopping, Banking) that keep logins and cookies apart
- Command bar (⌘K), address bar suggestions, link previews, saved workspaces and automatic tab tidy-up
- Bookmarks with live Safari bookmark sync, history, a reading list (⇧⌘D), highlights and notes
- Reader mode, read aloud, translate, full-page screenshots (⇧⌘S), dark mode for every site and focus mode
- Video controls and picture-in-picture, web panels for Calendar and Gmail, and custom keyboard shortcuts
- Safari Web Extensions from apps on your Mac, which ask before reading each site

## Claude
- Quick answers right in the address bar, and a side panel that can chat and use your tabs
- Explain or summarize selected text, rewrite what you type, and talk to Claude by voice
- Compare tabs, summarize YouTube videos, check whether a site looks legitimate, and get a weekly report
- Smart bookmarks that Claude sorts into folders, and "find a page I've seen" from your history
- Watch a page and get an alert when it changes
- Claude never sees private tabs or pages with a password box, and asks before closing tabs or sending forms

## Privacy and security
- Ad, tracker and pop-up blocking, cookie controls and automatic cookie-banner rejection
- Fingerprinting protection, link tracking removal, Global Privacy Control and email masking
- HTTPS upgrade with a warning for insecure sites, Google Safe Browsing and download scanning
- Passwords in the macOS Keychain with Touch ID autofill, a password generator and 2FA codes
- Per-site permissions, per-site Lockdown Mode, and a site info and certificate panel

## Music and search
- A Spotify mini player along the bottom of the window (Spotify Premium)
- Image and video search grids from DuckDuckGo

## Good to know
- Vela updates itself. Turn on Settings ▸ General ▸ Get beta updates to try new features early.
- Vela isn't notarized by Apple, so the first time you open it, right-click Vela ▸ Open (or use System Settings ▸ Privacy & Security ▸ Open Anyway).
